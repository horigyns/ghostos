# Changelog

## 0.4.0: first public release (2026-11-16)

GhostOS, organized around what needs your attention.

- **Board** (⌘1): one ranked queue across projects. Needs action: questions Claude asked in open sessions, failed or unread scheduled runs, brief updates waiting for approval. Unfinished: open threads, uncommitted or unpushed work, unmerged branches, saved notes. Act on each in place; `j`/`k`, `↵`, `e` done, `s` snooze.
- **Sessions** (⌘2): a session as a work log with a "Where this stands" card, folded tool steps, notes pinned to messages, a context drawer (⌘.), and Claude Code's terminal UI one menu away.
- **Projects** (⌘3): projects by area, each with its brief, chats in folders, scheduled runs, memory and ideas.
- **⌘K** to go anywhere, run a command or start a session from a sentence; a **Scope** pill to focus on one project; a **Running** strip with live sessions and plan usage.
- Scheduled runs with a background runner and budget guard, project briefs and session summaries, Ghost's watch for unfinished work, layered rules and agents (also applied to Claude Code outside GhostOS on request), design systems, search, ideas, import from Claude, and brain sync between Macs.
